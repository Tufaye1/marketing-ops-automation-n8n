# Marketing Operations Automation (n8n)

This repository contains marketing operations workflows built using n8n to automate reporting, data processing, and AI-assisted insights for digital marketing teams.

## Use Cases
- Automated campaign performance reporting
- KPI aggregation from multiple platforms
- AI-assisted insight generation using LLM APIs
- Workflow standardization for recurring marketing operations tasks

## Tools & Stack
- n8n
- Excel / Google Sheets
- REST APIs
- OpenAI / LLM APIs
- Slack / Email integrations

## Example Workflow
**Campaign Performance Automation**
- Pulls campaign data from multiple sources
- Normalizes KPIs into a structured format
- Generates weekly performance summaries
- Sends insights to stakeholders automatically

![Campaign Reporting Workflow](docs/campaign-reporting-workflow.png)


## Notes
These workflows are designed for learning and demonstration purposes and can be adapted for real-world SaaS and marketing operations environments.
